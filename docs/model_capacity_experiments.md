## 第一阶段：五组独立 SG 规模对照

所有模型均为当前 CrystalCompositionEncoder＋SpaceGroupHead，从头训练；组成编码器同样参与学习。独立 SG 不读取 Flow 特征。五组仅改变 SG 头的两项结构配置。

| 编号 | 变动 | SG hidden_dim | 实际隐藏层 | 直接分类 MLP 宽度 | SG 头参数 | 独立 SG 总参数 |
|---|---|---:|---:|---:|---:|---:|
| S0 | 当前结构 | 256 | 3 | 512 | 1,700,440 | 1,879,256 |
| S1 | 只减宽度 | 128 | 3 | 256 | 653,912 | 832,728 |
| S2 | 只减深度 | 256 | 2 | 512 | 1,238,872 | 1,417,688 |
| S3 | 同时减宽、减深 | 128 | 2 | 256 | 537,816 | 716,632 |
| S4 | 只增加宽度 | 384 | 3 | 768 | 3,205,720 | 3,384,536 |

S0–S3 是 2×2 因子实验；S4 检查是否仍存在容量不足，避免只朝缩小网络的方向搜索。

核心比较在同一训练 seed 内进行：

- S1−S0、S3−S2：在两种深度下分别测量减宽效果。
- S2−S0、S3−S1：在两种宽度下分别测量减深效果。
- S3−S2−S1＋S0：观察宽度与深度是否存在交互作用。
- S4−S0：增宽是否有收益。

当前 `get_mlp` 的 `mlp_hidden_layers` 直接表示实际隐藏层数，两层和三层对应配置 2、3。本批历史计划与运行记录使用旧语义，分别保存为 1、2；复现脚本按计划中的 `actual_hidden_layers` 构造相同深度的网络。`sg_head.hidden_dim` 同时控制直接分类、候选群位置编码、候选群输出映射和兼容性评分 MLP 的内部宽度；直接分类宽度是该值的两倍。候选群 embedding 和 SG 输入输出特征仍为 256 维。本批测量的是整个 SG 头的规模，不能将效果单独归因于直接分类器。

## 统一数据与训练配方

| 项目 | 固定设置 |
|---|---|
| 训练 / 验证 | MP20 原划分 27,136 / 9,047，全量数据 |
| 输入 | 完整常规晶胞的元素计数 |
| 组成编码器 | CrystalCompositionEncoder，元素 128 维，隐藏 256 维 |
| 先验 | 相同组成可行性 mask、相同候选群 Wyckoff 目录与 compatibility 分支 |
| 优化器 | AdamW，lr=1e-4，weight decay=0 |
| Batch / 精度 | 256 / FP32 |
| 归一化 / dropout | 两个 SG 评分 MLP 隐藏层使用 LayerNorm、dropout=0.1 |
| 其他训练方法 | 无调度器、无 EMA、无标签平滑、无梯度裁剪 |
| 训练种子 | 42、123、2026，每组均运行三个种子 |
| 训练预算 | 每次 300 epochs，每轮验证，保留第 100、200、300 轮结果 |
| 独立 SG 损失 | 标准、未乘 0.1 的 SG 交叉熵；保持组成可行性 mask |
| checkpoint | 最高验证 Top-5；完全相同时取较低验证 NLL，再相同时取较早轮数 |

SG 分支中的 LN/dropout 不自动加到共享组成编码器或候选群 Wyckoff 位置编码器；沿用当前实现。第一阶段共 5×3=15 次独立 SG 训练。

若任一结构在至少两个 seed 中的最佳 Top-5 都落在第 271–300 轮，则全部 15 次运行从第 300 轮统一续到第 500 轮，恢复优化器和随机数状态。此规则在看结果前固定，避免只给某个模型更多训练机会。

旧独立 A/基线实验的学习率为 5e-4，并使用 weight decay=0.05、EMA、label smoothing、调度器和 BF16；不能直接复用其成绩充当本批 S0。此前 A＋Flow 的 83.83% 保留为系统参照，不计入这批宽度/深度因果比较。

## 配对与选模规则

相同 seed 下，各结构使用相同组成编码器初始权重、相同材料顺序和相同训练预算。材料打乱使用独立 Generator，防止模型初始化或 dropout 消耗不同随机数后改变 batch 顺序。不同形状的参数使用相同初始化分布；不同宽度的随机权重、dropout 掩码不能宣称逐元素相同。

当前 Joint 构造顺序先初始化 Flow、再初始化组成编码器、最后初始化 SG 头。CPU 审计会对三个 seed 的全部五个结构检查共享组成编码器与 Flow 初始 state_dict 哈希完全一致。因此第二阶段只改 SG 头配置时，可以保持其他两个模块配对初始化。

第一阶段报告各 seed 的验证 Top-5、跨 seed 均值和标准差，以及相对 S0 的配对差值。同时报告同轮结果和各自选出的 checkpoint，不能只展示五组中最幸运的一个 seed。辅助指标为 Top-1、NLL、ECE（10 个等宽区间）、eval 模式训练/验证差距、参数量、每轮耗时、峰值显存。未见和低频原型的分组频次仅由训练集统计，不作为模型输入。

候选选取预先固定为：找出跨三个 seed 的平均最佳 Top-5 距最高均值不超过 0.20 个百分点的结构，从中选择 SG 头参数最少者。0.20 个百分点是性能与成本的工程取舍阈值，不是统计等价证明。若选中 S0，则不自动重复提交结构完全相同的 Joint。

对选出的非 S0 候选，额外用尚未参与结构筛选的 seed=3407 运行 S0 和候选，使用相同最终 epoch 预算。这增加 2 次独立 SG 训练，用于检查候选是否依赖筛选时的随机种子，不在此 seed 上重新搜索五组。若候选低于 S0 超过 0.20 个百分点，将结果标记为不稳定，暂缓昂贵的 Joint 验证。该复核仍使用相同验证集，不属于独立数据测试。

## 第二阶段：完整 Joint 验证

仅比较 J0＝当前 S0 结构与 J1＝通过复核的候选结构，均从头训练 Joint；不将独立 SG 预训练权重直接加载进 J1，否则会额外改变初始化/训练策略。

| 项目 | J0 与 J1 共同设置 |
|---|---|
| Seed | 42、123、2026 |
| Epochs | 1000，不因验证 CE 上升提前停止 |
| 损失 | 0.1×SG CE＋1×Flow CE |
| Flow | CrystalGNN：256 维、4 层、8 头，其余设置保持当前配置 |
| 数据、优化器、正则化 | 与当前 WD=0 Joint 一致，沿用上表 |
| 验证噪声 seed | 固定 42，与训练 seed 分开记录 |
| GWA | 每 100 轮，同一完整验证集 |
| 生成预算 | 预测 Top-5 群×每群 4 条，50 个 Flow 步，batch_size=128 |
| 解码与匹配 | 组成守恒解码；重复候选计入预算；包含等价原点/设置 |
| 周期采样 seed | 所有训练 seed 均固定用采样 seed=42 |
| 选 checkpoint | 验证 Joint GWA@20 最高；完全相同时选较早轮数 |

同时保留真群条件下每材料 20 条轨迹的 GWA，作为 Flow 诊断。它与 Joint 中每候选群 4 条轨迹的预算不同，二者差值不能全部解释为空间群错误。

每个训练 seed 选定 checkpoint 后固定权重，在采样 seed=42、314、2718 下复评 Joint GWA。后两个 seed 的结果不反过来重新选择 checkpoint。分别呈现训练 seed 波动与同 checkpoint 的采样波动，不把它们混成大量独立训练重复。最终配置和 checkpoint 锁定后再评估测试集，不使用测试分数继续选结构。

主要结论看完整 Joint GWA@20；SG Top-5、GWA@1、真群 GWA、条件模板命中率、组成正确率和成本是辅助指标。失败分解分别统计真群未进 Top-5，以及真群进入 Top-5 但没有正确等价模板。逐材料配对区间只描述固定训练及采样结果下的材料抽样不确定性，不能代替训练重复。

第二阶段最多 2×3=6 次 Joint。现有 WD=0、seed=42 运行完成后，如果配置、源代码和评估协议核对一致，可复用其中 J0 的一次，新增最多 5 次；不满足复用条件则重新配对训练，不能把历史曲线直接当严格对照。两组现有长任务按原计划完成。

## 后续可选：Flow 深度实验

在 SG 结构固定后，以第二阶段同结构的 4 层 CrystalGNN 为对照，只将 `model.decoder.num_gnn_layers` 改成 2，运行相同三个 seed、相同训练和 GWA 协议，新增 3 次 Joint。该组不属于首批必做实验。

保持 `decoder.hidden_dim=256`。若将它也改为 128，会同时改变共享组成编码器、Flow 和 SG 输入维度，无法将结果解释成仅 Flow 容量变化。若未来需要同时研究 SG 和 Flow 缩小的交互作用，补齐“SG 原始/候选 × Flow 4/2 层”四格，而不是只比较两个同时改变的模型。

本批也不同时搜索学习率、WD、dropout、SG loss 权重或增加 A 编码器。这些可以作为后续独立实验，当前结论限定在预先固定的训练配方下，不能据此声称某个规模在所有优化设置下最优。

## 资源与交付

首批 15 次 SG，加候选复核最多 2 次；通过复核后才进入最多 5 次新增 Joint（前提是现有一个基准可复用）。先使用空闲 GPU 1、2，单次训练占一张 GPU；GPU 0、3 上现有任务结束后再使用四卡，避免覆盖日志或争抢显存。
